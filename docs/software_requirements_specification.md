## 2. 软件功能需求详细规格 (Functional Specifications)

### 2.1 用户认证与权限控制子系统 (SWR-USR)

#### SWR-USR-001: 角色与按钮级权限控制软件规格 (无权限直接关闭)
* **功能描述**：软件必须实现基于 RBAC 的前端菜单隐匿、按钮级 DOM 物理移除与后端 API 路由双重拦截。
* **软件输入**：用户登录成功后获取的 `role_code: ['ADMIN' | 'SUPERVISOR' | 'ENGINEER' | 'TECHNICIAN']` 权限标识。
* **业务逻辑与实现规则**：
  * **侧边栏菜单级收敛**：在导航组件中通过 `v-if="authStore.isAdmin"` 严格受控，非 `ADMIN` 角色（包括 `SUPERVISOR`、`ENGINEER`、`TECHNICIAN`）的侧边栏完全不渲染“用户与班组管理”和“系统设置与审计”入口。
  * **前端全局权限指令 `v-permission`**：前端全局定义并注册 `v-permission="['ADMIN', 'ENGINEER']"` 指令。在元素挂载（`mounted`）生命周期中判定，若当前用户的 `role_code` 不在允许列表中，**直接调用 `el.parentNode?.removeChild(el)` 从 DOM 树中物理移除该节点**。
  * **受控按钮范围**：包括“录入设备”、“导出Excel”、“设备删除”、“编制新维护计划”、“升级版本快照”、“编制实操新课程”、“并发抢单认领”、“维修复盘提交”、“验收归档关闭”、“录入知识条目”等。
  * **后端双重拦截保障**：后端在每个受限 API 路由挂载 `Depends(require_role(...))` 依赖注入。非法调用时抛出业务异常，返回错误码 `10003: PERMISSION_DENIED`。
* **输出结果**：未授权角色登录后，无权限的菜单和按钮全部自动关闭/隐藏；整个操作链路杜绝“用户可见、点击却弹出权限不足错误提示”的违规体验。

#### SWR-USR-002: 专业工作类型数据范围动态过滤
* **功能描述**：根据用户绑定的 `work_type`（ELECTRICAL, MECHANICAL, AUTOMATION, GENERAL），在软件持久层自动注入查询过滤条件。
* **业务逻辑**：
  * 工程师与技术员发起任何设备列表、维护任务、故障单的查询请求时，后端数据访问层（Repository）自动附加 SQL 约束：
    `WHERE equipments.work_type = :user_work_type`（若为 `GENERAL` 或 `ADMIN` 则跳过）。
* **验收标准**：电气技术员调用通用查询接口时，返回结果集中设备 `work_type` 100% 均为 `ELECTRICAL`。

#### SWR-USR-003: 账号全生命周期管理与软禁用/软删除
* **功能描述**：软件实现账户的新增、编辑、启禁用与安全软删除全流程闭环，禁止物理级硬删除。
* **输入校验**：
  * `username`：3~32位字符，仅支持字母、数字及下划线。
  * `employee_no`：唯一工号，格式校验 `EMP-[A-Z0-9]{4,8}` 或标准工号。
  * `email`：符合 RFC 5322 邮箱格式标准。
* **软件处理**：
  * 提供 `PUT /api/v1/users/{id}` 支持管理员修改用户信息与启用/禁用状态（`is_active`）。
  * 提供 `DELETE /api/v1/users/{id}` 实现账号安全软删除（`is_deleted = TRUE`），保留历史数据审计关联。
  * 登录接口判定若 `is_active == FALSE` 或 `is_deleted == TRUE`，返回错误码 `10002: ACCOUNT_DISABLED`。

#### SWR-USR-004: 密码安全与强阻断改密控制
* **功能描述**：实现前端密码强度校验与强制改密的前后端双重防穿透阻断。
* **密码规则**：长度 $\ge 8$ 位，必须同时包含大写字母、小写字母、数字及特殊符号。
* **双重阻断实现**：
  * 后端：生成 JWT Token 时注入 `"fcp": true`。全局中间件拦截非改密接口，返回 `10008: FORCE_PASSWORD_CHANGE_REQUIRED`。
  * 前端：Vue Router 全局 `beforeEach` 守卫监测到 `fcp === true` 时，无条件跳转至 `/force-change-password`，隐藏主布局框架。

#### SWR-USR-005: 邮箱密码找回与一次性时效 Token
* **功能描述**：通过异步邮件发送重置链接，链接携带安全随机密钥。
* **处理机制**：生成 UUID 作为 Token，存入 Redis：`key="pwd_reset:" + token`, `value=user_id`, `ex=900`（15分钟）。重置密码成功后立即调用 `redis.delete()`，保证单次有效。

#### SWR-USR-006: 登录防护与生产单班次 8 小时长效会话
* **功能描述**：抵御暴力破解，并保障车间单班次 8 小时免重登连续作业。
* **软件处理**：
  * 密码错误时，Redis 中对应账户失败计数自增 1，TTL=900秒。达到 5 次将账户锁定，返回错误码 `10001: ACCOUNT_LOCKED` 并返回剩余秒数。
  * 后端 JWT Token 签名有效时长设定为 **480 分钟（8小时）**，覆盖标准工作班次，杜绝巡检打卡与工单处理中途凭据过期踢出。
  * 前端监听全局鼠标移动、按键与触摸事件。若连续 30 分钟无事件触发，清除本地 Token 并主动安全登出。

#### SWR-USR-007: 全局操作人审计自动注入
* **功能描述**：ORM 实体监听器在执行 `INSERT` 与 `UPDATE` 时，自动从当前请求上下文提取 `current_user.id`，回填至 `created_by` 与 `updated_by`。

#### SWR-USR-008: 操作级权限细粒度校验
* **功能描述**：按“录入、编辑、删除、导出、查阅”五维进行代码级鉴权，杜绝任何纵向/横向越权漏洞。

### 2.2 设备管理与位置层级子系统 (SWR-DEV)

#### SWR-DEV-001: 5级位置树与闭环检测物化路径
* **功能描述**：实现支持快速检索的树形位置分类，严格限制深度 $\le 5$ 且仅叶子节点挂载设备。
* **防成环算法**：当修改节点 `parent_id` 时，后端查询新父节点的 `tree_path`，若包含当前节点的 ID，则判定成环，抛出 `20003: CYCLIC_HIERARCHY_DETECTED`。
* **深度校验**：新节点的 `level_depth` 为 `parent.level_depth + 1`，若 $> 5$ 抛出 `20004: MAX_DEPTH_EXCEEDED`。

#### SWR-DEV-002: 层级节点防孤儿删除校验
* **功能描述**：删除节点前，在同一事务中检测：
  1. `SELECT COUNT(1) FROM equipment_locations WHERE parent_id = :id AND is_deleted = false`
  2. `SELECT COUNT(1) FROM equipments WHERE location_id = :id AND is_deleted = false`
  若任一项 $> 0$，抛出 `20001: CANNOT_DELETE_NODE_WITH_CHILDREN_OR_EQUIPMENT`。

#### SWR-DEV-003: 设备通用台账规范化录入
* **功能描述**：设备编码唯一性自动校验、责任工程师绑定、购置年限与维保周期录入。
* **表单校验**：设备编码支持条形码/二维码扫描自动填入，重复编码触发异步校验红字提示。

#### SWR-DEV-004: 11类设备专有参数强类型 Schema 校验 (反省改进)
* **功能描述**：针对 11 类设备，动态渲染专用表单并实施严格的类型边界校验。
* **软件 Schema 规范**：
  * **PLC**：`ip_address` (必须为合法 IPv4 地址，如 `^((25[0-5]|2[0-4]\d|[01]?\d\d?)\.){3}(25[0-5]|2[0-4]\d|[01]?\d\d?)$`)，`comm_protocol` 枚举校验。
  * **风机**：`air_volume_m3h > 0`，`air_pressure_pa > 0`，`rated_speed_rpm > 0`。
  * **电机**：`rated_power_kw > 0`，`insulation_class` 限制为 `['A', 'E', 'B', 'F', 'H', 'C']`。
  * **传感器**：`output_signal_type` 限制为 `['4-20mA', '0-10V', 'PNP', 'NPN', 'RS485']`。
  * 其余类型均定义对应的强类型子模型。

#### SWR-DEV-005: 设备有限状态机跃迁引擎
* **功能描述**：软件通过状态机服务严格控制设备状态变更：`RUNNING` $\leftrightarrow$ `MAINTENANCE_PENDING` $\leftrightarrow$ `FAULTY` $\leftrightarrow$ `SHUTDOWN` $\rightarrow$ `SCRAPPED`。非法跃迁抛出 `20005: INVALID_STATUS_TRANSITION`。

#### SWR-DEV-006: 工业级标签化附件与解耦存储 (反省改进)
* **功能描述**：实现附件与业务表单的直传解耦。上传文件时在 `equipment_files` 标记 `is_linked = FALSE`。业务表单保存时更新为 `TRUE`。未关联的孤儿文件由后台定时任务清理。

#### SWR-DEV-007: 设备多维组合复合查询
* **功能描述**：支持前端构建复合查询过滤对象，后端通过动态 SQL 构建器（Specification / SQLAlchemy Filter）实现高效索引覆盖检索，分页拉取。

#### SWR-DEV-008: 设备全生命周期电子履历时间轴组件
* **功能描述**：聚合目标设备的历次巡检记录、故障事件、更换备件与停机时长，按倒序渲染为交互式时间线。

#### SWR-DEV-009: Excel 导入解析器与数据清洗预览
* **功能描述**：前端提供模板下载，后端采用流式读取 Excel，逐行执行 Schema 校验，返回通过行数与错误单元格坐标（如 `第3行B列: IP地址格式错误`），预览确认后再事务性写入。

### 2.3 维护与巡检管理子系统 (SWR-MNT)

#### SWR-MNT-001: 维护计划编制与图文 SOP 编辑器
* **功能描述**：前端集成富文本编辑器，支持图文混排的 SOP 说明。支持设置维护周期（天）及生效时间范围。

#### SWR-MNT-002: 结构化巡检清单与标准配图渲染
* **功能描述**：支持动态增删检查项，每个检查项支持关联一张标准状态参考照片（如“正常油位刻度线照片”），方便移动端比对。

#### SWR-MNT-003: 维护计划版本快照固化机制
* **功能描述**：当维护计划被编辑保存时，计划版本自增（如 V1.0 $\rightarrow$ V1.1）。已派发的任务及历史巡检记录，永久保存其生成时引用的版本号与检查项快照，绝不变更。

#### SWR-MNT-004: 动态倒计时批处理调度 (反省改进)
* **功能描述**：每日零点执行倒计时更新任务。软件采用**游标分批拉取 (Cursor Chunking, size=100)**，单台设备更新失败进行异常捕获并记录审计日志，绝不中断批量处理流程。

#### SWR-MNT-005: 维护到期多时间点邮件防重调度
* **功能描述**：支持管理员勾选提前 7天、3天、1天或当天提醒。调度发信前必须执行幂等检查：`SELECT 1 FROM maintenance_notify_logs WHERE ...`，已发信则直接跳过，杜绝重复投递。

#### SWR-MNT-006: 维护任务自动派发工作台
* **功能描述**：设备倒计时到期时，系统自动生成 `MAINTENANCE_PENDING` 任务工单，推送至责任工程师与技术员的待办池中。

#### SWR-MNT-007: 车间平板现场逐项巡检打卡
* **功能描述**：技术员必须对清单中的每一个条目进行单选判定（正常/异常）。若判定为异常，表单自动将“异常现象描述”与“现场拍照上传”设置为强制必填，未满足禁止提交。

#### SWR-MNT-008: 巡检异常单事务联锁生成故障单 (核心软件规格)
* **功能描述**：`POST /api/v1/maintenance/inspections/submit` 聚合接口在**单一本地数据库事务**内完成：
  1. 写入 `inspection_records`；
  2. 写入 `inspection_record_details`；
  3. 若包含异常项，自动构造 `fault_records`（来源为 `INSPECTION_AUTO`，状态为 `OPEN`）；
  4. 回填 `fault_id` 至异常巡检明细；
  5. 跃迁目标设备状态为 `FAULTY`；
  6. 事务成功后触发异步邮件通知事件。

#### SWR-MNT-009: 维护超时报警与持续催办
* **功能描述**：超过截止时间 3 天未完成打卡的任务，状态自动置为 `OVERDUE`，每日早上 08:00 投递催办邮件至部门管理员与工程师。

#### SWR-MNT-010: 维护按时完成率多维度统计分析
* **功能描述**：后台聚合服务按设备、工种、月份统计按时完成率指标，生成符合 ECharts 格式的序列化数据供前端大盘渲染。

#### SWR-MNT-011: 巡检明细全量报表 Excel 导出
* **功能描述**：支持将选定时间区间内的巡检打卡明细（包含逐项检查结果与异常文字）导出为标准 Excel 报表。

### 2.4 故障时效与闭环流转子系统 (SWR-FLT)

#### SWR-FLT-001: 故障双来源归一化接入
* **功能描述**：无论是由巡检异常自动联锁生成，还是由车间技术员主动填报，均进入统一的故障流转池，并以 `source_type` 明确标识。

#### SWR-FLT-002: 故障核心要素标准化录入
* **功能描述**：必填故障标题、故障描述、系统分类、部件位置、严重等级（严重/一般/轻微）、关联设备及现场证据照片。

#### SWR-FLT-003: 故障录入实时智能排查推荐 (前端与引擎协同)
* **功能描述**：
  * 前端：技术员在“故障描述”文本框键入时，设置 300ms 防抖函数 (`debounce`)，异步调用 `/api/v1/faults/recommend-similar`。
  * 后端：优先匹配当前设备型号与系统，提取候选集，计算分词加权得分，过滤得分 $\ge 60\%$ 的前 3 条结果返回。
  * 缓存：若查询无结果，向 Redis 写入空值占位（TTL=60s），防止频繁击穿数据库。

#### SWR-FLT-004: 故障状态流转控制
* **功能描述**：状态按 `OPEN` $\rightarrow$ `IN_PROGRESS` $\rightarrow$ `RESOLVED_PENDING_REVIEW` / `RESOLVED` $\rightarrow$ `CLOSED` 推进，支持打回重新流转。

#### SWR-FLT-005: 工程师并发接单状态乐观锁 (反省改进)
* **功能描述**：工程师认领工单时，执行带前置状态条件的原子更新：
  `UPDATE fault_records SET status = 'IN_PROGRESS', ... WHERE id = :id AND status = 'OPEN'`
  若受影响行数等于 0，则直接抛出业务异常 `40003: FAULT_ALREADY_CLAIMED`，并在前端提示“该故障单已被其他工程师认领”。

#### SWR-FLT-006: 维修复盘根因与处理步骤强制填报
* **功能描述**：在调用解决工单接口时，`root_cause` 与 `solution_steps` 字段实施强校验（字符长度均不得低于 10 个字符），未满足直接拦截。

#### SWR-FLT-007: 标定典型故障案例与知识打标
* **功能描述**：工程师或管理员可在解决后勾选 `is_featured_case = TRUE`，打上专属金标，并在知识库中置顶展示。

#### SWR-FLT-008: SLA 响应与解决时效自动轮询监控
* **功能描述**：后台定时任务每 5 分钟扫描未闭环工单，计算响应超时与解决超时。严重故障响应超 30 分钟未接单，自动标记 `is_sla_response_breached = TRUE` 并发送升级催办邮件。

#### SWR-FLT-009: 故障明细及复盘方案导出
* **功能描述**：支持导出包含故障现象、根本原因、解决方案及耗时明细的 Excel 汇总表。

### 2.5 知识库引擎与培训赋能子系统 (SWR-KB & SWR-TRN)

#### SWR-KB-001: 故障闭环异步知识入库
* **功能描述**：监听故障单关闭事件，异步提取故障现象、根本原因、处理步骤及标签，自动生成 `knowledge_articles` 记录，建立倒排全文索引。

#### SWR-KB-002: 知识库全文模糊检索
* **功能描述**：基于 PostgreSQL `pg_trgm` 或全文向量索引，支持多关键词模糊搜索，前端对命中词汇实施高亮展示。

#### SWR-KB-003: 知识库多维分类聚合筛选
* **功能描述**：支持按设备类型、系统位置、是否典型案例进行多维 Facet 聚合过滤。

#### SWR-KB-004: 双阶段相似度推荐计算引擎

* **功能描述**：SMTP 邮件服务器页面可视化配置与持久化保存 (支持动态热更新与密码脱敏)、在线自检发信、通知分组路由、全生命周期事件邮件调度队列、通用 Excel 导入导出流式解析器、180 天只读防篡改审计日志流水、附件二进制魔数校验与孤儿文件定时清理。

#### SWR-NFR-001 ~ 005: 软件非功能属性与性能指标
* **安全**：bcrypt 散列存储、SQL 参数化防止注入、XSS 标签转义、接口级防越权过滤。

* **容量**：在无需分库分表下稳定支撑 1000 台设备、10000 条故障单、50000 条巡检记录。
* **高可用与一致性**：核心资产软删除、巡检异常联锁单一数据库事务提交。
* **兼容**：完美兼容 Chrome 90+、Edge 90+、Firefox 90+ 及主流工控平板触控操作。
