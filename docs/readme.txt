工厂PLC自动化设备管理系统，本系统是为了方便维护和管理部门人员完成设备的检修和日常维护，为了简化设备管理，设备状态管理，设备检修状态管理，设备检修流程标准化，设备检修培训记录与培训，需要提供如下功能，目前的需求比较简单，所以需要在完成如下功能的基础上，进行功能细节推理和细化。
用户管理
1. 拥有系统账户
2. 系统账户可以增加工程师账号和技术员账号
3. 系统账户拥有最大权限
4. 工程师账号拥有编辑，删除、修改权限，导出权限--每条记录最好能看到修改人是谁

权限类型：
1. 编辑
2. 修改
3. 删除
4. 导出
5. 录入

工程师和技术员  按照工作类型不同，适当给相应权限。


设备维护：

1. 可以建立设备维护内容  维护内容可以编辑  上传图片     技术员操作查看时  正常可以直接选择正常，异常时  录入异常现象
2. 具备录入维护时间功能，时间可以倒计时，也可以具备管理员权限修改。
3. 倒计时后具备邮件提醒功能，邮箱由管理员添加

设备管理：

1. 录入设备台账及设备参数，
2. 设备台账可以录入层级分类
3. 可以上传照片
4. 可以上传PDF文件或Word文件等
5. 具备检索功能

故障记录：
1. 具备检索功能
2. 技术员录入信息分类
故障描述、故障系统、故障位置、故障解决、时间日期、上传照片（故障现场照片，解决故障方法）
